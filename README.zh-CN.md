# Note Text Align

给 **Markdown 笔记正文**设置横向对齐 —— 左 / 居中 / 右 / 两端。Obsidian 原生**完全没有**这个设置。

- 在笔记里右键 → **笔记对齐** → 选一个位置。当前生效的那项打勾；没设过则「清除」打勾。
- 命令面板 → **笔记正文：左对齐 / 居中 / 右对齐 / 两端对齐 / 清除对齐**。

对齐写在**笔记自己的 frontmatter** 里：

```yaml
---
cssclasses: [nta-center]
---
```

正文一个字符都不动，属性面板里看得见，删掉那一行（或执行「清除对齐」）就还原。

## 什么情况下生效

| 场景 | 右键菜单 | 对齐效果 |
|---|---|---|
| 实时预览（编辑态） | ✅ | ✅ 编辑层和渲染层都生效 |
| 源码模式 | ✅ | ✅ |
| 阅读视图 | —（那儿没有编辑器） | ✅ 用命令面板即可 |
| 笔记被嵌进白板卡片 | — | 交给 **Canvas Node Align** 管（见下） |

## 为什么只有水平方向

白板卡片需要垂直对齐（顶部 / 居中 / 底部），因为它有固定高度、文字可能比卡片矮。
整篇笔记没有这个问题：它从顶部开始、按需滚动，「整篇垂直居中」只是把滚动位置挪一下，
没有意义。所以这里只有 4 种水平对齐。

## 设置

- **最后一行也拉满** —— 按排版规范，两端对齐**不拉伸最后一行**，于是任何语言的一句话段落看起来都和左对齐一样。打开这个开关连最后一行也拉满（`text-align-last: justify`）。默认关闭，长段落一般不需要。

## 配套插件

- **[Canvas Node Align](https://github.com/jiangbianyan-gif/obsidian-canvas-node-align)** —— 白板里的对齐：卡片正文、分组 / 连线 / 文件名标签、右键九宫格、垂直位置。**笔记被嵌进卡片时**的正文对齐也归它管。
- 本插件只管「笔记单独打开」时的情况。两边各管各的场合，不会互相打架。

## 已知限制

- 卸载插件后 `nta-*` 还留在笔记的 `cssclasses` 里，但样式没了 ⇒ 会回到左对齐。想清干净就删掉那条属性。
- 以前用 **Canvas Node Align 2.x** 设过对齐的笔记，类名是 `cta-note-*`，本插件照样认（样式表里也留着对应规则）。在那篇笔记上重新点一次位置，类名就会换成 `nta-*`。
- 对齐作用于笔记的正文文字；图片、表格、代码块有各自的布局，不跟着走。
- 你自己写的、恰好也用 `nta-` 开头但不是那四个位置的类名，本插件不会动。

## 安装

社区插件里搜 **Note Text Align**（等目录审核通过后），或把 `main.js`、`manifest.json`、`styles.css`
放进 `<你的库>/.obsidian/plugins/note-text-align/`，再到「设置 → 第三方插件」里启用。

## 开发

```
main.js         插件源码（ES2017，无打包器、无依赖）
styles.css      对齐规则
test/note.test.js       92 条断言：frontmatter 读写、类名契约、样式守卫、菜单接线守卫
test/build.test.mjs     测发布工具链本身
tools/build.mjs         `npm run build` —— 社区目录要跑的就是这条
tools/check-manifest.mjs 清单规则，发版前本地先过一遍
```

```bash
npm test          # 两个测试文件
npm run build     # 和社区目录跑的同一条命令
npm run verify    # 清单 + 构建 + 测试
```

## 隐私

不联网、不埋点、不读笔记内容。它唯一会写的东西，就是你在哪篇笔记上点了对齐，就往那篇笔记的 frontmatter 写一个 `cssclasses` 条目。
